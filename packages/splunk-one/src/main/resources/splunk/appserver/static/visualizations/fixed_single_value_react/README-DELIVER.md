## What this is

This is a **Splunk dashboard custom visualization** implemented as:

- Splunk AMD entry: `visualization.js` (generated by Webpack; bundles **React 18**)
- Formatter UI: `formatter.html`
- Styles: `visualization.css`
- Picker preview: `preview.png`
- Registration snippet: `visualizations.conf.snippet`

Splunk directory name / viz id: **`fixed_single_value_react`**

## Build (generates `visualization.js`)

From `packages/splunk-one/`:

```bash
yarn install
yarn build
```

This repo’s `webpack.config.js` emits the viz bundle to:

- `packages/splunk-one/src/main/resources/splunk/appserver/static/visualizations/fixed_single_value_react/visualization.js` (for the Splunk app tree)
- `packages/splunk-one/deliver/fixed_single_value_react/` (a “zip this folder” handoff copy)

## Install into Splunk (typical)

Assume the Splunk app folder is **`$SPLUNK_HOME/etc/apps/so_BUI_pickulationts/`** (matches this repo’s `app.conf` id).

Copy:

- `visualization.js`
- `visualization.css`
- `formatter.html`
- `preview.png`

To:

- `$SPLUNK_HOME/etc/apps/so_BUI_pickulationts/appserver/static/visualizations/fixed_single_value_react/`

Merge `visualizations.conf.snippet` into:

- `$SPLUNK_HOME/etc/apps/so_BUI_pickulationts/default/visualizations.conf`

Restart Splunk (or follow your org’s Splunk Web reload practice).

## Data expectations (SPL)

The viz selects the **last “all-numeric” column** in the panel results (same behavior as the vanilla version).

Example SPL:

```spl
| makeresults count=6
| streamstats count as i
| eval value=random()%100
| fields value
```

## Important namespace note

The formatter keys resolve to:

`display.visualizations.custom.so_BUI_pickulationts.fixed_single_value_react.*`

If you install into an app whose id is not `so_BUI_pickulationts`, update the `NS` string in the Webpack entry (`visualization.amd.jsx`) and rebuild.
