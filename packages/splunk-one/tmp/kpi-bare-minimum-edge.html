Bare-minimum OOTB cases (no custom tools)

Like dropping an OOTB Line, Single Value (+ spark), or Pie on a panel: Auto fields only — no annotations, High/Critical, inspector, or text/info extras.

Happy path
kpi_line

Line — bare timechart

| timechart span=1h count

Chart-only. Hover points.

kpi_sparkline

Sparkline — bare timechart

| timechart span=1h count

Major + delta + spark.

pie_chart

Pie — bare stats by

| stats count by category

Outside labels + %. Legend off.
