| table example — custom value field + multiple lines

Paste the SPL in Splunk Search, switch to Visualization → SplunkStuff - KPI loaded line, then set Format as below. Charts under the SPL render the same result locally.

X comes from the host column (no _time). Primary Y = custom value field. Other numeric columns become extra lines.

1. Paste this in Search

| makeresults count=8
| streamstats count as i
| eval host=case(
    i=1,"web-01",
    i=2,"web-02",
    i=3,"api-01",
    i=4,"api-02",
    i=5,"db-01",
    i=6,"db-02",
    i=7,"cache-01",
    i=8,"cache-02"
  )
| eval count=case(
    i=1,42, i=2,55, i=3,38, i=4,61, i=5,27, i=6,33, i=7,19, i=8,24
  )
| eval latency=case(
    i=1,120, i=2,98, i=3,145, i=4,110, i=5,160, i=6,132, i=7,88, i=8,95
  )
| eval errors=case(
    i=1,2, i=2,1, i=3,4, i=4,0, i=5,3, i=6,2, i=7,1, i=8,0
  )
| table host count latency errors

2. Format settings

Data → X category field name
host
Data → Y value field name
count (left panel) or latency (right)
Custom → Series mode
Auto or Multi series
Appearance → Background
Transparent (Search-like)
  1. Primary line + major number = the custom Y value field.
  2. Remaining numeric columns (latency, errors, …) draw as extra lines.
  3. Only want one line? Series mode → Single KPI.
